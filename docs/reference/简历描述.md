简历描述：

高并发秒杀系统

核心技术： Spring Boot、MyBatis、MySQL、Redis、Caffeine、RocketMQ、Docker
• 流量治理与多级缓存： 设计验证码、活动级流量闸门、用户维度令牌与限流机制实现请求分层准入，结合 Caffeine + Redis +
MySQL 三级缓存降低热点商品查询压力；对照压测中 MySQL 读 QPS 约 90 → 2，Redis QPS 约 140 → 45。
• Redis 原子库存扣减： 活动发布时将库存预热至 Redis，使用 Lua 将库存校验、扣减与售罄标记封装为原子操作，避免 Redis
库存校验和扣减之间的并发竞争，并结合数据库事务回滚实现 Redis 库存补偿。
• 异步库存同步与幂等： 基于 RocketMQ 事务消息与库存流水状态机制实现异步库存同步，通过事务回查处理消息状态异常；针
对重复投递导致的重复扣库问题，以库存流水 ID 作为业务唯一标识实现消费幂等，并通过并发压测验证库存一致性。
